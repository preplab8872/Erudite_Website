Eruweb package validation
=========================

Applied security changes
------------------------
- Both IP reputation and human-verification cookie caches use 86,400 seconds (24 hours).
- Cookie trust is recalculated on each protected request; the cookie payload does not store cookie_score.
- The payload does not store route_access or route_checked_at.
- IP cache reuse checks the HMAC of the current visitor IP and the actual cache age.
- Provider-unavailable/quota fallback I=50 is not stored as a successful IP cache entry.
- A fresh Turnstile token forces fresh Siteverify validation; otherwise the valid 24-hour H cache is reused.
- The existing formula and the H=1 plus F>=0.6 access condition are unchanged.
- Security-check endpoints remain outside RiskCheckMiddleware; the return route is evaluated again after the verification POST.
- Declining optional device fingerprinting clears only the fingerprint fields and does not delete the essential IP/H cache cookie.
- Fixed config/services.php to read TURNSTILE_SITE_KEY, TURNSTILE_SECRET_KEY, and IP2LOCATION_API_KEY.

Checks completed
----------------
- PHP syntax: 57 project PHP source files passed php -l.
- Laravel route registration: php artisan route:list passed.
- Security-check Blade source: direct Blade compiler compilation passed.
- Homepage script.js and Backend resources/js/app.js: node --check passed.
- Runtime config lookup: all three expected security environment variables were detected as configured in the source environment.

Checks blocked by this build environment
----------------------------------------
- PHPUnit could not start because PHP extensions DOM, mbstring, and xmlwriter are unavailable.
- Laravel Pint could not start because PHP extensions mbstring and xml are unavailable.
- Composer CLI is not installed in this build environment.

Sensitive/runtime files omitted from the ZIP
---------------------------------------------
- Backend/.env is intentionally omitted because it contains deployment credentials. Keep your original .env separately and copy its values when deploying. The corrected .env.example is included.
- Runtime logs, session files, compiled Blade views, and cache data are omitted; Laravel recreates them.
